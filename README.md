# World Development Analytics Dashboard

A Data Studio dashboard comparing development indicators across countries, built as part of a data analytics workshop.

## About the data
The dataset is synthetic. It was generated for the workshop and the values are approximations, not official figures. It is not sourced from the World Bank or UNDP, and specific numbers should not be cited as facts. The dashboard is built for practicing data visualization, not for drawing real-world conclusions.

## What I did
- Structured country-level data
- Built the dashboard in Data Studio
- Added interactive filters by region and income group to explore the data
- Compared countries across themes such as GDP per capita, demographics and population, environment and sustainability, university enrollment and AI readiness, and wealth and quality of life, among others
